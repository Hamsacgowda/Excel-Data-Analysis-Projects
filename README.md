# 📌 Project 1: Employee Payroll

### Description

A payroll management worksheet that calculates employee salaries based on hourly wages, working hours, overtime hours, bonuses, and total monthly pay.

### Features

* Employee salary calculation
* Overtime calculation
* Bonus calculation
* Total monthly payroll
* Summary statistics

  * Maximum
  * Minimum
  * Average
  * Total

### Excel Skills Used

* SUM
* MAX
* MIN
* AVERAGE
* Basic arithmetic formulas
* Cell referencing
* Data organization
